# Project

This Git repository contains the application-specific source code for a live
CodeIgniter 4 production site.

The repository root corresponds to CodeIgniter's `app/` directory.

The parent directory contains the CodeIgniter installation, including
composer.json, spark, public/, vendor/, writable/, and third-party assets.

## Safety

You may freely inspect and modify files in this repository.

Unless explicitly instructed:
- do not modify files outside this repository
- do not modify the database
- do not run migrations
- do not modify .env
- do not install packages
- do not restart services
- do not commit or push
- do not delete files
